# EG Tree Services LLC

Full React redesign of [egtreeservicesllc.com](https://egtreeservicesllc.com/) — Cleveland, TX tree care, landscaping, and lot clearing.

## Stack

- React + Vite + React Router
- Local project media in `public/img/`

## Run

```bash
npm install
npm run dev
```

## Routes

`/`, `/about`, `/services`, `/tree-services`, `/landscaping`, `/lot-clearing`, `/projects`, `/contact`
